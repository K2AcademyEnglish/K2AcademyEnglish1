# 케이투학원 영어 학습 사이트 (K2AcademyEnglish)

학원 학생이 영어 문제를 풀고 과제를 제출하며, 선생님(관리자)이 문제은행을 만들고 과제·주간평가를 내는 웹사이트입니다.

- **사이트 주소:** https://k2academyenglish.github.io/K2AcademyEnglish1/
- **화면(프론트엔드):** 이 폴더의 HTML·JS·CSS 파일 → GitHub Pages에서 그대로 서비스
- **서버(백엔드):** `Code.gs` 한 파일 → Google Apps Script 웹 앱
- **데이터:** Google 스프레드시트 3권 (문제은행 / 기록부 / 단어장)

별도 빌드 과정·패키지 설치·데이터베이스가 없습니다. 파일을 고쳐서 올리면 그대로 반영됩니다.

---

## 1. 전체 구조 한눈에 보기

```
 학생·선생님 브라우저
        │  (index.html + *.js + *.css, GitHub Pages)
        │
        │  POST { func: '함수이름', args: [...], auth: {id, token} }
        ▼
 Google Apps Script 웹 앱 (Code.gs 의 doPost)
        │  1) PUBLIC_API_ 목록에 있는 함수만 실행
        │  2) ADMIN_API_ 목록에 있으면 관리자 인증 확인
        ▼
 Google 스프레드시트
   ├─ 문제은행 (QBANK_SHEET_ID)      : 시험지별 시트, MasterIndex
   ├─ 기록부   (QBANK_LOG_BOOK_ID)   : 멤버, 과제, 풀이 기록, 과제결과, 알림·포인트
   └─ 단어장   (VOCAB_SHEET_ID)      : 학생별 단어장 시트, 오타정정, 기록
```

- 화면에서 서버를 부르는 곳은 `api-utils.js`의 **`gsCall`**(및 옛 방식 `google.script.run` 흉내) 하나로 모여 있습니다. 서버 주소는 같은 파일 맨 위 `GAS_WEB_APP_URL`입니다.
- 옛 Google 스크립트 주소(`doGet`)로 들어오면 새 사이트로 보내는 안내 화면만 나옵니다.

## 4. 데이터(구글 시트) 구조

시트 ID는 `Code.gs` 위쪽 상수(`QBANK_SHEET_ID`, `QBANK_LOG_BOOK_ID`, `VOCAB_SHEET_ID`)에 있습니다.

### 4-1. 기록부 (`QBANK_LOG_BOOK_ID`)
| 시트 | 내용 |
|---|---|
| `멤버` | A: ID, B: 이름, C: 권한(`관리자`/`학생`/`휴원`), D: 학생은 담당 관리자 ID · 관리자는 **비밀번호**, 메모 열 |
| `과제` | 배부한 과제 목록(과제ID, 학생, 문항 QID 목록(JSON) 등) |
| `Logs_2026_4Q` … | 학생 풀이 기록(분기별로 새 시트). 예전 통합 기록은 `StudentLogs` |
| `과제결과_2026_4Q` …, `과제결과_색인` | 과제별 최신 답(빠른 조회용) |
| `알림`, `알림_읽음`, `포인트내역`, `교환신청` | 공지·포인트·교환권 |

### 4-2. 문제은행 (`QBANK_SHEET_ID`)
- **시험지 1개 = 시트 1개, 문항 1개 = 열 1개**(B열부터). A열은 행 이름표입니다.
- 행은 17줄로 고정(`QB_ROWS`): `ID, 출처, 유형, 연계, 난이도, 질문, Box1~4, 선택지 1~5, 정답, 해설`
- 문항의 고유 번호(**QID**)는 `시트이름!열번호`(B열 = 1)입니다. 풀이 기록·과제가 이 QID로 문항을 가리키므로, **문항 열을 손으로 끼워 넣거나 지우면 기존 기록이 엉뚱한 문항을 가리키게 됩니다.** 순서 바꾸기는 사이트의 문제은행 화면(드래그)에서 하세요. 이미 풀이 기록이 있는 문항은 자동으로 막습니다.
- `MasterIndex` 시트: 출제 화면에서 쓰는 전체 문항 색인. 출처가 비어 있는 열과 `분류_` 시트는 빠집니다. 문제은행 화면에서 저장하면 자동 갱신됩니다.
- `양식` 시트: 새 시험지를 만들 때 복사하는 틀.
- 시트 2행 메모 `K2_HIDDEN_SOURCE:` = 학생 화면에서 숨긴 시험지 표시.

**시트 이름 규칙**
| 예시 | 뜻 |
|---|---|
| `h2_25_09` | 고2 2025년 9월 모의고사 원문 (`h`=고, `m`=중) |
| `h2_25_09기출` | 그 모의고사 지문으로 학교 시험에 나온 문제. ID 예: `h2_25_09_39_GC001` |
| `h2_25_09변형` | 변형 문제. ID 예: `…_BH001` |
| `h2_26_E2YBM(P)_1변형` | 교과서(영어2 YBM 박) 1과 변형 |
| `h3_27_ST` | 2027학년도 수능특강. ID 예: `h3_27_ST_1-G`(1강 Gateway), `h3_27_ST_1-3`, `h3_27_ST_T1-8`(Test 1의 8번) |
| `분류_…` | **분류 시트**: 출처가 섞인 문제를 잠시 모아 두는 곳. 출제 목록에 안 나옵니다. |

**문항 안의 태그** (질문·지문·선택지에 쓸 수 있음)
- `<b>굵게</b>`, `<u>밑줄</u>`, `<i>기울임</i>`, `<sub>`/`<sup>`
- `<r>…</r>` 오른쪽 정렬 + 본문보다 1.5pt 작은 글씨. 지문 끝 각주에 씁니다 — 예: `<r>* soft shoulder: 포장하지 않은 갓길</r>`
- `<c>…</c>` 가운데 정렬(요약문 화살표 등), `<box>…</box>` 테두리 상자, `<table>…</table>` 간단한 표
- `<red>` `<blue>` `<green>` `<orange>` 글자색
- `<image>` 그림: 이 문항 ID와 같은 이름의 그림을 `img/학년/연도/문항ID.jpg`(없으면 `img/문항ID.jpg`)에서 찾아 넣습니다. 변형 문항은 그림이 없으면 원본 문항 그림을 씁니다.
  `<image:h3/26/ST/h3_26_ST_8-1>`처럼 경로를 직접 적을 수도 있습니다(확장자 생략 시 .jpg).
- 어법·어휘·흐름·삽입·도표 유형은 ①~⑤를 **지문 안에** 넣고 선택지 칸은 비웁니다. 삽입은 `( ① )` 모양.

### 4-3. 단어장 (`VOCAB_SHEET_ID`)
- 학생마다 `ID(이름)` 시트 하나. 이름을 바꿔도 `ID(`로 시작하는 시트를 찾아 이어 씁니다.
- `오타정정`, `기록`(학습 기록) 시트.

## 5. 문제은행에 문제 넣는 방법

문제은행 화면에서 **[📥 가져오기]** 를 누르고 글을 붙여 넣거나 PDF를 고릅니다. 양식을 알아서 구별합니다.

| 양식 | 결과 |
|---|---|
| 모의고사 (18~45번) | 번호별 유형 자동, 정답·해설 PDF도 따로 넣을 수 있음 |
| EBS 수능특강·수능완성 PDF | 강별 Gateway·Exercises·Test로 나눠 ID 자동(`h3_27_ST_1-G` …). 같은 PDF에 해설이 있으면 정답·해석·풀이까지, 없으면 책 끝 **빠른 정답표**에서 정답만. 별책 「정답과 해설」 PDF는 저장 후 가져오기 창의 **[✅ 정답·해설]** 탭에서 넣습니다. |
| 학교 시험지(내신 기출) | 문항마다 붙은 출처 꼬리표(`[25년 9월 39번]`, `[1과]`)와 끝의 정답표를 읽음 |

- 가져오기 창 맨 위에 **점검 결과**가 나옵니다(코드 빠짐, 번호 어긋남, 번호를 추정한 문항, 정답 없는 문항). 노란 경고가 붙은 문항만 원본과 비교하면 됩니다.
- **도표 문항**은 그림을 `img/…` 폴더에 올리고 Box1에 `<image>`(또는 경로를 적은 `<image:…>`)를 넣어야 합니다. 예: EBS 그림은 `img/h3/26/ST/`에 있으므로 `<image:h3/26/ST/h3_26_ST_8-1>`.
- **출처가 섞인 시험지**: [＋ 새 시험지] → `📦 분류 시트`에 체크해 만들고, 그곳으로 가져와 저장한 뒤 **[시험 시트로 옮기기]**. 꼬리표를 보고 `h2_25_09기출` 같은 시트와 다음 ID 번호를 자동으로 정해 주며, 없는 시트는 새로 만듭니다.
- 목록에서 Shift/Ctrl로 여러 문항을 골라 한꺼번에 고칠 수 있고, 끌어서 순서를 바꿀 수 있습니다. 목록 옆 **노란 점** = 난이도·Box1·정답 중 빈 칸이 있는 문항.

PDF 분석기는 화면(`qbank.js`)에서 돌아가며, PDF 글꼴·배치에 따라 일부 규칙을 보강해야 할 수 있습니다. 새 교재가 잘 안 읽히면 점검 결과와 PDF를 함께 확인하세요.

## 6. 고치고 배포하는 방법

### 6-1. 화면(JS·CSS·HTML)을 고쳤을 때
1. 파일을 고칩니다.
2. **`index.html`에서 그 파일의 버전을 올립니다.** 예: `qbank.js?v=20261117k` → `qbank.js?v=20261118a`
   (안 올리면 학생 브라우저가 예전 파일을 계속 씁니다.)
3. GitHub 저장소에 올립니다(커밋·푸시). 1~2분 뒤 사이트에 반영됩니다.

### 6-2. 서버(`Code.gs`)를 고쳤을 때
1. Apps Script 편집기에 `Code.gs` 전체를 붙여 넣고 저장합니다.
2. **배포 → 배포 관리 → ✏️(연필) → 버전: 새 버전 → 배포.**
   ⚠️ "새 배포"를 만들면 주소가 바뀌어 사이트가 끊깁니다. 반드시 기존 배포의 **새 버전**으로 올립니다.

### 6-3. 새 서버 함수를 화면에서 쓰려면
- `Code.gs` 위쪽 **`PUBLIC_API_`** 목록에 함수 이름을 넣어야 화면에서 부를 수 있습니다.
- 관리자만 써야 하는 함수는 **`ADMIN_API_`에도** 넣습니다. 그러면 서버가 관리자 인증을 먼저 확인합니다.
- 관리자 함수는 맨 앞에 `_guardDirect_();`를 둡니다(사이트를 거치지 않은 호출 차단).
- 여러 사람이 동시에 시트를 고칠 수 있는 작업은 `_withLock_(() => { … })` 안에서 합니다.

## 7. 로그인과 보안

- 학생: ID만으로 로그인. `멤버` 시트 C열이 `휴원`이면 로그인이 막힙니다.
- 관리자: ID + 비밀번호(`멤버` D열). 로그인하면 서버가 ID·비밀번호로 만든 토큰을 주고, 관리자 기능을 부를 때마다 함께 보내 확인합니다. **비밀번호를 바꾸면 기존 토큰은 무효**가 되어 다시 로그인해야 합니다.
- 학생 ID는 바꾸지 않습니다. 풀이 기록·과제·포인트·단어장이 모두 ID로 이어져 있습니다(학생 관리 화면에서도 ID 변경은 막혀 있습니다).

| `POINT_EXCHANGE_UNIT` | 교환권 1장에 필요한 포인트 | 100 |
| `NOTICE_DEFAULT_DAYS` | 공지 기본 게시 기간(일) | 7 |
| `TAROT_ON` / `TAROT_COST` / `TAROT_DAILY` | 타로 켜기, 1회 포인트, 하루 횟수 | true / 10 / 1 |
| `TAROT_TOPICS` | 타로 주제(`love`를 빼면 연애운 숨김) | today, study, friend, love, money |
| `MANAGER_PW_MIN` | 관리자 비밀번호 최소 길이 | 4 |

타로 카드·색·아이템 개수를 바꾸면 `tarot.js`와 `Code.gs`의 `TAROT_*_COUNT`를 함께 맞춰야 합니다.

## 9. 자주 생기는 문제

| 증상 | 원인·해결 |
|---|---|
| 고쳤는데 사이트가 그대로 | `index.html`의 `?v=` 버전을 안 올렸거나, 올리기 전 `index.html`이 예전 것으로 덮여 있음. 올리기 전에 버전 줄을 꼭 확인하세요. (동기화 프로그램이 `index.html`을 예전 버전으로 되돌린 적이 여러 번 있습니다.) |
| "허용되지 않은 함수입니다: …" | 그 함수가 `PUBLIC_API_`에 없거나, `Code.gs`를 고친 뒤 **새 버전 배포**를 안 함 |
| "관리자 인증이 만료되었습니다" | 관리자 비밀번호가 바뀜 → 로그아웃 후 다시 로그인 |
| 출제 화면에 새 시험지가 안 보임 | 출처 칸이 비었거나 `분류_` 시트, 또는 숨김 설정. 문제은행에서 저장하면 MasterIndex가 갱신됩니다. |
| 서버가 느림 | 관리자 [📢 공지·포인트] → [⏱ 속도]에서 함수별 처리 시간을 확인 |
| 문항 열을 시트에서 직접 옮겼더니 기록이 이상함 | QID가 열 번호라서 생기는 문제. 순서 바꾸기는 사이트 문제은행 화면에서만 하세요. |
